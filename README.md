# Alaya Token 首页与视频工作台

基于九章云极 Alaya Token 品牌视觉的前端原型：高级感首页、文本/视频模型入口、视频生成体验工作台。

## 文件结构

- `index.html` — 首页（Hero + 文本/视频入口）
- `models.html` — 模型广场（搜索、分类筛选、模型卡片）
- `video.html` — 视频生成工作台（提示词 / 风格 / 画幅 / 案例）
- `assets/css/styles.css` — 设计系统与样式
- `assets/js/main.js` — 首页神经网络背景与滚动显现
- `assets/js/models.js` — 模型广场数据与搜索
- `assets/js/studio.js` — 工作台交互与案例数据

## 本地预览

用浏览器直接打开 `index.html`，或在本目录启动任意静态服务器后访问。

当前若已有本地服务，可打开：`http://127.0.0.1:5173/`
